# Contributing to LocalSift 👋

First of all, **thank you for being here!** LocalSift is a learning project — contributions from beginners are especially welcome.

## 🐛 Reporting a bug
1. Go to the [Issues](https://github.com/danilo-labs/LocalSift/issues) section.
2. Click **New issue** and choose the **Bug report** template.
3. Fill in as much as you can — a bug we can reproduce is a bug we can fix.

## 💡 Suggesting a feature
Open a new issue using the **Feature request** template. Explain why the feature would be useful.

## 🚀 Submitting a Pull Request
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/my-new-feature`).
3. Commit your changes (`git commit -m 'Add some feature'`).
4. Push to the branch (`git push origin feature/my-new-feature`).
5. Open a Pull Request.

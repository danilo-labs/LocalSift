# Security Policy

## Supported Versions

LocalSift is currently in early development. The latest version (v1.x.x) is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

LocalSift is designed as a **local-first application**. All document processing happens on your machine, and no data is sent to any external server. 

However, if you discover a security vulnerability in the Python server (`localsift_server.py`) or the JavaScript frontend (`index.html`), please **do not open a public issue**. 

Instead, please report it privately by:
1. Contacting the maintainer directly (via GitHub or email if provided in the profile).
2. Providing a detailed description of the vulnerability and steps to reproduce it.

I will acknowledge your report as soon as possible and work on a fix. Thank you for helping keep LocalSift safe!
